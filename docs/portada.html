🚀 Instalación

git clone https://github.com/TU_USUARIO/RockyBot.git
cd RockyBot
npm install
node index.js

💬 Uso

  • !capturar — Combate salvaje
  • !retar @usuario — Batalla entre entrenadores
  • !estado — Estado de tu Pokémon
  • !team — Mostrar tu equipo
